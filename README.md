# SHIN · Legacy link bridge

This small GitHub Pages site preserves old Seller University reader URLs.
The current project is [haloshin/seller-university](https://github.com/haloshin/seller-university).

Only the known `/amazon-seller-university-transcripts/` prefix is redirected. Course query/hash parameters are preserved. Unknown URLs stay on the not-found page. No analytics, cookies, credentials or course content are stored here.

Run `node test-redirect.js` to verify routes.
